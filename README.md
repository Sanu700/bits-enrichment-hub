## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Bun (preferred) or npm

### Installation

```bash
git clone https://github.com/Sanu700/BITS-Hyd-SWD-Demo-Site
cd BITS-Hyd-SWD-Demo-Site
```

### Run Locally

```bash
bun install
bun run dev
```

Or with npm:

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site locally.
